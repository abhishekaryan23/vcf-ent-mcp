Fill identity and VCF settings

06 / Review flags

Check these before rollout.

Short, source-backed prompts for a human reviewer. Pattern matches are not confirmed vulnerabilities.

!
Review candidate · Configuration + server path

HTTP listener defaults

The HTTP listener is plain HTTP with no TLS option. The starter config binds it to 127.0.0.1, but a config without server.host binds to all interfaces. Set server.host and put an approved TLS gateway in front of it before remote use.

src/vcf_enterprise_mcp/config/settings.py:44
!
Review candidate · No direct call found

Production checks appear uncalled

The settings object defines production checks, but no direct call was found in application source. Confirm the deployment path invokes them before accepting traffic.

src/vcf_enterprise_mcp/config/settings.py:127
!
Review candidate · Server construction + registry defaults

Real-VCF behaviour is unverified

The real-VCF provider wiring (URLs, per-component auth, secret references) is built from the config and tested against simulators and Broadcom's published specs, not against live appliances. Treat real-VCF read results as unproven until you have validated them in a lab.

src/vcf_enterprise_mcp/core/server.py:78
